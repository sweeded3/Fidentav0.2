# Структура репозитория

```text
fidenta-site/
├── index.html        # главная страница
├── invest.html       # инвестиционный раздел
├── lk.html           # личный кабинет собственника
├── 404.html          # страница ошибки для GitHub Pages
├── robots.txt        # базовые правила индексации
├── .nojekyll         # отключение Jekyll на GitHub Pages
├── .gitignore        # исключения для Git
├── README.md         # инструкция по запуску и публикации
└── docs/
    └── STRUCTURE.md  # описание структуры
```

## Маршруты

- `/` или `/index.html` - главная.
- `/invest.html` - инвестиции.
- `/lk.html` - личный кабинет.

## Дальнейшая декомпозиция

Когда дизайн стабилизируется, можно вынести общие стили и скрипты:

```text
assets/
├── css/
│   └── main.css
├── js/
│   └── main.js
└── images/
```

Пока все оставлено внутри HTML, чтобы репозиторий сразу работал на GitHub Pages без сборки.

# Fidenta Static Site

Статический сайт УК «Фидента» для размещения в GitHub Pages или на любом обычном хостинге без сборки.

## Страницы

- `index.html` - главная страница.
- `invest.html` - раздел инвестиций.
- `lk.html` - концепт личного кабинета собственника.

## Запуск локально

Откройте `index.html` в браузере или запустите простой локальный сервер:

```bash
python3 -m http.server 8080
```

После запуска откройте:

```text
http://localhost:8080
```

## Публикация через GitHub Pages

1. Создайте репозиторий на GitHub.
2. Загрузите содержимое этой папки в корень репозитория.
3. Откройте `Settings -> Pages`.
4. Выберите `Deploy from a branch`.
5. Branch: `main`, folder: `/root`.
6. Сохраните настройки.

## Примечания

- Сайт не требует Node.js, Vite, Webpack или другой сборки.
- CSS и JavaScript пока находятся внутри HTML-файлов.
- Внешние изображения подключены по URL, часть изображений в личном кабинете встроена в HTML.
- Файл `.nojekyll` добавлен для корректной отдачи статических файлов GitHub Pages.
